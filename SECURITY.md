# Security policy

Do not include Google OAuth tokens, OAuth client files, recordings, unpublished
research data, or local StimTrace configuration in issues, pull requests, or release
archives. StimTrace releases do not contain organisational OAuth configuration; users
provide their own optional Google Drive OAuth Desktop client file locally.

If you discover a vulnerability, use GitHub's private vulnerability-reporting or
security-advisory feature for this repository. Do not disclose exploitable details
in a public issue before a fix is available.

StimTrace is research-use software and is not intended for clinical decisions.
